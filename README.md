## 🌟 About This Project

Welcome to my **Week 3 Cybersecurity Lab Repository!**

This repository documents my practical learning experience with password recovery and hash generation as part of the Networkwalks Cybersecurity & Ethical Hacking Program.

## 🟣 Project Module 1 — John the Ripper (JTR)

**Objective:** Recover the password of a protected PDF using John the Ripper on Kali Linux.

- 🔹 Extracted the PDF password hash using `pdf2john`.
- 🔹 Saved the hash in a text file.
- 🔹 Used John the Ripper with a wordlist.
- 🔹 Successfully recovered the password and opened the protected PDF.

**Result:** <img src="https://img.shields.io/badge/PASSWORD_RECOVERY-SUCCESS-16A34A?style=flat-square" />

**Objective:** Practice file hash generation and explore dictionary-based password testing using Networkwalks online tools.
